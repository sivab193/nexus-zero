Map coordinates, but for links.

Nexus Zero began with a simple question: if a place can be shared as three memorable words, why can’t a link?

It draws inspiration from what3words, which made geographic coordinates speakable, and Jorge Luis Borges’ The Library of Babel, an imagined library containing every possible book. Nexus Zero applies that sense of addressable possibility to the web: every supported URL becomes a deterministic coordinate in a vast field of words.

The crucial difference is that these aren’t saved aliases. The coordinate contains the route. The browser can calculate the URL back from the words—even offline—without looking up a stored link.

Nexus Zero is an independent project and is not affiliated with what3words.
